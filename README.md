# Azooz AI for iPhone

تطبيق مساعد ذكي أصلي للآيفون باستخدام SwiftUI، بواجهة عربية واتجاه RTL.

## الحالة الحالية
- واجهة محادثة عربية.
- إرسال الرسائل وعرضها داخل المحادثة.
- بدء محادثة جديدة.
- رد تجريبي محلي مؤقت؛ لم يتم ربط نموذج ذكاء اصطناعي حقيقي بعد.

## البناء
يفتح المشروع باستخدام Xcode على macOS. سير عمل GitHub Actions يبني نسخة iOS Simulator للتحقق من سلامة المشروع.

## ربط الذكاء الاصطناعي
يجب ربط التطبيق بخادم وسيط آمن يحتفظ بمفتاح مزود الذكاء الاصطناعي. لا تضع مفتاح API داخل تطبيق iOS أو مستودع GitHub.

## التثبيت على iPhone
بناء المحاكي ليس قابلاً للتثبيت على iPhone الحقيقي. يتطلب التوزيع على الجهاز توقيع iOS وإعداد provisioning مناسباً، ويمكن لاحقاً استخدام TestFlight.
